# TextQuest Keyboard Shortcuts Reference

Complete reference guide for all keyboard shortcuts in TextQuest.

## Quick Start

| Category      | Keys                                                      |
| ------------- | --------------------------------------------------------- |
| **Movement**  | WASD (cardinal), Q/E (diagonal), Shift (modifier)         |
| **Targeting** | Tab (cycle), ~ (nearest enemy), 0 (self), Esc (clear)     |
| **Abilities** | 1-5 (primary), Shift+1-5 (secondary), Ctrl+1-5 (tertiary) |
| **UI**        | I (inventory), C (character), E (equipment), H (help)     |
| **Chat**      | Enter (toggle), G (guild), H (group), T (tell), / (emote) |

---

## Keyboard Layout Map

### Standard QWERTY - Left Hand (Movement & Modifiers)

```
┌─────┬─────┬─────┬─────┬─────┐
│ Esc │  1  │  2  │  3  │  4  │  Function Keys (Abilities 1-4)
├─────┼─────┼─────┼─────┼─────┤
│ Tab │  Q  │  W  │  E  │  R  │  Q/E = diagonal NW/NE move
│     │ NW  │ N   │ NE  │ act │
├─────┼─────┼─────┼─────┼─────┤
│Caps │  A  │  S  │  D  │  F  │  WASD = cardinal movement
│     │ W   │ S   │ E   │ stand
├─────┼─────┼─────┼─────┼─────┤
│Shft │  Z  │  X  │  C  │  V  │  Z/C = diagonal SW/SE move
│     │ SW  │stop │ SE  │ alt │
└─────┴─────┴─────┴─────┴─────┘

Legend:
  N  = North (W key)
  S  = South (S key)
  E  = East (D key)
  W  = West (A key)
  NE = Northeast (E key)
  NW = Northwest (Q key)
  SE = Southeast (C key)
  SW = Southwest (Z key)
```

### Standard QWERTY - Right Hand (Abilities)

```
┌─────┬─────┬─────┬─────┬─────┐
│  5  │  6  │  7  │  8  │  9  │  1-5 = Primary abilities
├─────┼─────┼─────┼─────┼─────┤  Shift+1-5 = Secondary
│  T  │  Y  │  U  │  I  │  O  │  Ctrl+1-5 = Tertiary
│ inv │ alt │ alt │ inv │ alt │
├─────┼─────┼─────┼─────┼─────┤
│  G  │  H  │  J  │  K  │  L  │  0 = Self target
│ chat│group│cycle│cycle│ alt │  ~ = Nearest enemy
├─────┼─────┼─────┼─────┼─────┤  Tab = Cycle targets
│Shft │  B  │  N  │  M  │ ,/. │  ; = Next target
│buff │ buff│ buff│ map │ prev│  , = Previous target
└─────┴─────┴─────┴─────┴─────┘
```

## Navigation Shortcuts

### Basic Movement

- **W** - Move North
- **A** - Move West
- **S** - Move South
- **D** - Move East
- **Q** - Move Northwest (diagonal)
- **E** - Move Northeast (diagonal)
- **Z** - Move Southwest (diagonal)
- **C** - Move Southeast (diagonal)
- **Shift + Movement** - Run / Sprint (increased speed)

### Map & Waypoints

- **M** - Open/Close Map
- **Shift + M** - Toggle Minimap
- **P** - Open Waypoints
- **Shift + P** - Add Waypoint at Current Location
- **Ctrl + P** - Clear All Waypoints
- **Ctrl + M** - Toggle Compass
- **I** - Show Zone Information

## Combat Shortcuts

### Targeting

- **Tab** - Cycle to next target
- **Shift + Tab** - Cycle to previous target
- **0** - Target Self
- **~** (tilde) - Target nearest enemy
- **Shift + ~** - Target nearest ally
- **Esc** - Clear target
- **Ctrl + L** - Lock target (prevent auto-cycling)

### Abilities (5-slot hotbar)

#### Primary Tier (Unmodified)

- **1** - Cast Ability 1
- **2** - Cast Ability 2
- **3** - Cast Ability 3
- **4** - Cast Ability 4
- **5** - Cast Ability 5

#### Secondary Tier (Shift)

- **Shift + 1-5** - Cast Ability 6-10

#### Tertiary Tier (Ctrl)

- **Ctrl + 1-5** - Cast Ability 11-15

### Combat Actions

- **"** (quote) - Auto-attack toggle
- **F** - Stand ground (stay in place)
- **Shift + F** - Follow target
- **X** - Stop movement
- **Ctrl + C** - Toggle combat mode

## Customization

### Enabling Custom Keybinds

1. Set `enable_custom_bindings = true` in `keyboard-shortcuts.toml`
2. Create `~/.textquest/keybinds.toml` with your custom bindings
3. Restart the client to apply changes

### Conflict Detection

The system warns about conflicting bindings by default. To allow conflicts:

```toml
allow_conflicting_binds = true
```

### Profiles

Available profiles in `keyboard-shortcuts.toml`:

- **default** - Standard WASD + numpad layout
- **vi** - VI editor style (hjkl for movement)
- **emacs** - Emacs style (Ctrl-based navigation)
- **gaming** - Optimized for fast-paced combat
- **accessibility** - Single-hand and adaptive options

## Accessibility Features

### Sticky Modifiers

Hold a modifier key once to activate; press again or another key to deactivate:

```toml
sticky_modifiers = true
```

### Repeat Delay & Rate

Adjust keyboard repeat for accessibility:

```toml
repeat_delay_ms = 500    # Time before key repeat starts
repeat_rate_ms = 100     # Time between repeats
```

### Text-to-Speech

Enable announcements (requires TTS system):

```toml
enable_tts = true
announce_target = true
announce_ability_ready = true
```

## Multi-Key Sequences (Combos)

Execute abilities in sequence:

- **Ability 1 + Ability 1** - Charged Attack
- **Ability 1 + Ability 3 + Ability 5** - Execute Combo
- **Ability 10 + Ability 14** - Emergency Heal Sequence
- **Ability 6 + Ability 7 + Ability 8** - Buff Rotation

Time limit between presses: 3 seconds

## Integration with Help System

These shortcuts are automatically exported to the in-game help system and searchable through:

- **F1** in-game opens this reference
- **Help** menu > Keyboard Shortcuts
- Command palette: `help shortcuts`
