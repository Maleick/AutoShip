FROSTREAVER TUI TARGET
======================

This mockup reflects the composite 3-screen model:
- Overview: fleet command center with collapsible sections
- Tactical: map + spawn list + named/nav rail on one screen
- Inspect: player + target + hex + live spawn list

Behavior:
- The spawn list and map are always visible together.
- The selected spawn is marked on the map with `◎`.
- The selected character remains marked with `◆`.
- The navigation rail can be collapsed with `z` when it has focus.
- `Enter` on a spawn switches to Inspect and populates the hex dump.
