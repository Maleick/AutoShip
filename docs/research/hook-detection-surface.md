## Migration Priority

The following current hooks should be migrated to HWBP first because they are currently highest-risk and provide the largest detection reduction if changed to no-code-modification interception:

1. `SystemFingerprint` (`textquest-dll/src/hooks/fingerprint.rs`) — currently a retour detour.
2. `CDisplay::RealRender_World` (`textquest-dll/src/hooks/render.rs`) — currently a retour detour.
3. DX11 vtable hooks (`IDXGISwapChain::Present`, `ID3D11Device::*`, `ID3D11DeviceContext::*` in `textquest-dll/src/hooks/dx11_null.rs`) — currently pointer swaps in COM vtables.
4. Packet capture targets (`WSASend`, `WSARecv`) once implemented in `textquest-dll/src/hooks/packet_hook.rs` — install path is currently TODO and should use HWBP or equivalent stealth path if added.
