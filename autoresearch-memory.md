# Autoresearch Memory

- Base all work on fresh `origin/master`.
- Live is primary. Test is historical/reference-only.
- `TextQuest-Ghidra` is canonical for immutable evidence, manifests, baseline selection, and Ghidra intake and analysis flow.
- `TextQuest` is canonical for code, `docs/wiki/`, runbooks, automation, and lightweight references.
- `docs/wiki/` is the canonical docs surface. The GitHub wiki is a landing page only.
- GitHub tracking uses issues, milestones, and PRs. GitHub Projects are retired.
- Sub-issues are only for true epics or release buckets, and parent epics stay open until their child issues are complete.
- If a migration gap is not solved in the current PR, open or update a strict issue immediately.
- Never merge active Test defaults or Test-only workflow guidance into `master`.
