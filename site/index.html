TextQuest
EverQuest multibox controller · TLP servers

A Rust-based orchestration engine for managing large box crews on EverQuest Time-Locked Progression servers. Combines a live terminal dashboard, automated camp management, and a group coordination engine into a single operator-facing control plane.

Key Features
Everything you need to run a large crew on a TLP server
⚔️
Camp Automation
Pull, fight, loot, and med cycle with configurable thresholds. Handles named spawns, CC assignments, and CH chains automatically.
🗺️
Navigation
Waypoint-based movement with navmesh pathfinding. Stick-to-target, camp radius enforcement, and zone-aware routing.
👥
Group Management
Dynamic group builder with role-based slot assignment. Track HP, mana, and cast state across all box slots simultaneously.
🔮
Multi-Client Control
Discovers and manages all EQ client processes. Staggered launch and login coordination for large box counts.
🌐
Web Dashboard
Axum + React SPA for remote monitoring. Session overview, loot tracking, DPS meters, and economy panels.
🧠
Soul Engine
Character personalities powered by configurable trait profiles. Persistent autobiographical memory, social graph tracking, and idle behavior generation.
Architecture
Four workspace crates, designed for live Windows deployments with macOS dev support
Crate
textquest
External orchestrator. Reads game state, renders the TUI, manages clients, runs the camp loop, and coordinates group actions.
Crate
textquest-dll
Injected payload (cdylib). Hooks internal EQ functions for direct control — movement, targeting, casting, and chat.
Crate
textquest-common
Shared types, IPC protocol, offset database, navigation primitives, and combat data structures used by all crates.
Crate
textquest-web
Axum backend serving a React SPA. REST API + WebSocket for real-time session monitoring and configuration.
Quick Start
Runs in demo mode on macOS and Linux — live mode requires Windows with EQ running
# Clone and build
git clone https://github.com/Maleick/TextQuest.git && cd TextQuest
cargo build
 
# Run TUI (demo mode on macOS, live on Windows)
cargo run
 
# Run tests
cargo test
 
# Dev preflight (same as CI)
python3 scripts/dev-preflight.py
