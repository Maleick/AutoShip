# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.9.x   | :white_check_mark: |
| < 2.9   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities by emailing [security@teamoperator.red](mailto:security@teamoperator.red) or opening a private security advisory on GitHub.

We aim to respond within 48 hours and will keep you informed throughout the remediation process.
